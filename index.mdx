# Welcome to Parallax

Parallax is a decentralized, EVM-compatible blockchain protocol inspired by Bitcoin’s time-tested economic model and secured by XHash Proof of Work.  

This documentation is your primary resource to understand how Parallax works, how to connect to the network, and how to contribute to its ecosystem.

---

## Documentation Structure

Our documentation is divided into six sections. Each changes on its own schedule, and only the client documentation is versioned.

### 📖 Protocol Specification

The protocol itself: its foundations, architecture, and advanced concepts. Start here to understand **what Parallax is** and **why it works the way it does**.

- **Foundational Topics**: Introduction to Parallax, LAX, accounts, blocks, transactions, gas and fees, and the Parallax Virtual Machine (PVM).  
- **Parallax Stack**: Components that make up the network, how nodes communicate, and how the stack fits together.  
- **Advanced**: Bridges, token standards, oracles, networking and the data structures used in the Parallax protocol.

### 💻 Parallax Client

The official Parallax Client implementation: everything you need to install, configure, and run your own node. It has one version of its documentation per major release, `v2.x` for the current one and an archived `v1.x`.

- **Getting Started**: Hardware requirements, installation, and first steps.  
- **Fundamentals**: Command-line options, security, sync modes, account management, databases, backups, logs, pruning, config files, and more.  
- **Interacting with the Client**: JSON-RPC server and namespaces, JavaScript console, GraphQL server, and contract interaction.  
- **Developers**: Guides for dApp developers, client developers, PVM tracing, and contributing to the codebase.  
- **Monitoring & Tools**: Node health, metrics, and helper utilities.  

### 👛 Parallax Wallet

Parallax Wallet, the desktop wallet with a full node built in: installing it, accounts, sending and receiving, your node, contacts, signing messages, hardware wallets, offline signing, settings, AI assistants and troubleshooting.

### ⛏️ Hashwarp

Hashwarp, the official GPU miner for XHash: setup, pool mining and troubleshooting.

### 🧭 Beginner Guides

Step-by-step guides for running a node, wallets, CPU mining and AI assistants.

### 🏦 Exchange Integration Guide

What an exchange needs to list LAX: running a node, deposits, withdrawals, confirmations and the network status API.
