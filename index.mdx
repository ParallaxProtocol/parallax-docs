Parallax is a decentralized, EVM-compatible blockchain protocol inspired by Bitcoin’s time-tested economic model and secured by XHash Proof of Work.  

This documentation is your primary resource to understand how Parallax works, how to connect to the network, and how to contribute to its ecosystem.

## Network at a glance

| | |
|---|---|
| **Coin** | LAX, 18 decimals |
| **Chain ID** | `2110` |
| **Consensus** | Proof of work, [XHash](/protocol/foundational-topics/consensus/algorithms/xhash) |
| **Block time** | 10 minutes, with difficulty adjusted every block (ASERT) |
| **Block reward** | 50 LAX, halving every 210,000 blocks (about 4 years) |
| **Supply cap** | 21,000,000 LAX. No premine |
| **EVM** | Berlin. Legacy and access-list transactions, no EIP-1559 |
| **Public RPC** | `https://rpc.parallaxprotocol.org`, for testing. Run your own node for anything serious |
| **Block explorer** | [explorer.parallaxprotocol.org](https://explorer.parallaxprotocol.org) |
| **Network status** | [status.parallaxprotocol.org](https://status.parallaxprotocol.org) |

The full list, with address and transaction formats, is in the
[Network reference](/exchange-integration/network-reference). To add Parallax
to MetaMask, see [Setting up MetaMask](/guides/wallets/metamask).

## Get help

- **Ask an AI assistant**: the [Parallax MCP server](/guides/ai/parallax-mcp) lets Claude and other assistants search these docs and read the chain.
- **Check the network**: [status.parallaxprotocol.org](https://status.parallaxprotocol.org) shows whether blocks, nodes and mining are healthy.
- **Report a problem**: open an issue in the right repository of the [ParallaxProtocol GitHub organization](https://github.com/ParallaxProtocol).
- **Follow the project**: [@prlxchain on X](https://x.com/prlxchain).
